# Apps

Direktori ini menyimpan aplikasi siap distribusi yang dipaketkan langsung di BASKA Hub. Struktur dibuat berdasarkan platform lalu aplikasi.

## Isi folder

| Path | Fungsi |
|---|---|
| `android/` | Paket aplikasi untuk Android. Saat ini berisi KuisinGo. |
| `README.md` | Dokumentasi direktori aplikasi. |

## Konvensi

Setiap aplikasi sebaiknya memiliki subfolder sendiri, file paket distribusi, metadata paket, dan README yang menjelaskan cara instalasi serta versi. Jangan menyimpan credential atau data pengguna di dalam paket/metadata repository.
