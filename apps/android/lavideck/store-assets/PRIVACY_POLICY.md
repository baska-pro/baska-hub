# Kebijakan Privasi LaviDeck

Pembaruan: 10 Oktober 2026.

LaviDeck memindai nama dan ikon aplikasi yang dapat dibuka di perangkat
untuk menampilkan serta mengelompokkan pintasan. Data ini diproses secara
lokal dan tidak dikirimkan kepada pengembang ataupun pihak ketiga.

Favorit, folder, aplikasi tersembunyi, shortcut website, pengaturan tema,
serta data konfigurasi lainnya disimpan dalam penyimpanan privat aplikasi.
Jika pengguna memilih ekspor backup, pengguna memilih sendiri lokasi
penyimpanan berkas backup. File backup tidak menyertakan PIN.

LaviDeck tidak menggunakan koneksi internet untuk mengirimkan data
pribadi, tidak menampilkan iklan, dan tidak memiliki sistem akun.

Pengguna dapat memilih untuk memberikan izin "Akses Penggunaan" Android
untuk menampilkan aplikasi paling sering dibuka. Izin itu opsional, dapat
dicabut kapan saja melalui Pengaturan Android, dan riwayat tersebut tidak
dikirim ke server.

Biometrik diproses oleh mekanisme autentikasi sistem Android. Lavi
Shortcuts tidak membaca atau menyimpan sidik jari/wajah pengguna.
PIN disimpan sebagai hash yang diperkuat, bukan angka PIN dalam bentuk teks.

Shortcut situs web menggunakan browser pengguna; pengunjung situs web tunduk
pada kebijakan privasi situs tujuan.

Menghapus data aplikasi di Pengaturan Android menghapus konfigurasi lokal.
Hapus aplikasi untuk berhenti menggunakan fitur.
