# LaviDeck v2.2.0 (10 October 2026)
- Renamed from Lavi Shortcuts to LaviDeck; package and certificate preserved.
- App drawer uses recycled rows; avoids building icons for all apps at once.
- Faster category/menu transitions and reduced redundant package scans.
- Stable scroll state across tabs/categories/rotation.
- More reliable press-and-drag experience: sticky Kategori and Folder targets.
- Fallback move chooser and existing three-dot options.
- Default Light Mode maintained.
- Signed APK/AAB, refreshed icon/feature assets and build sources.
Known limits: physical Android devices not accessible for touch-validation;
Google Play approval is not implied by a successful build.
