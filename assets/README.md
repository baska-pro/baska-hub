# Assets

Folder aset visual yang digunakan oleh dokumentasi dan identitas repository BASKA Hub.

## File

| File | Fungsi |
|---|---|
| `banner.svg` | Banner utama BASKA Hub dalam format SVG; digunakan sebagai elemen branding/dokumentasi dengan kualitas vektor. |
| `README.md` | Dokumentasi folder aset. |

Aset di folder ini sebaiknya bersifat publik, tidak memuat credential, dan menggunakan nama file stabil agar referensi README/dokumentasi tidak rusak.
