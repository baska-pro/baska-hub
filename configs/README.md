# Configs

Direktori ini disediakan untuk contoh atau konfigurasi publik BASKA Hub yang aman disimpan di repository.

## File saat ini

| File | Fungsi |
|---|---|
| `README.md` | Menjelaskan tujuan folder dan aturan penyimpanan konfigurasi. |

Saat ini belum ada file konfigurasi operasional lain di folder ini.

## Aturan

- Simpan hanya template/default yang tidak sensitif.
- Jangan commit token, password, API key, cookie, private key, atau konfigurasi mesin pribadi.
- Konfigurasi runtime pengguna seharusnya berada di direktori data lokal BASKA, bukan repository.
