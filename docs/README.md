# Documentation

Folder dokumentasi resmi BASKA Hub dan source halaman dokumentasi GitHub Pages.

## File

| File | Fungsi |
|---|---|
| `ARCHITECTURE.md` | Ringkasan arsitektur BASKA Hub dan hubungan komponen utama/runtime. |
| `AUTO_SYNC.md` | Penjelasan mekanisme sinkronisasi otomatis repository/katalog publik. |
| `PRIVATE.md` | Kebijakan dan perilaku terkait repository/private catalog agar data private tidak bocor ke katalog publik. |
| `USAGE.md` | Panduan penggunaan CLI BASKA dan command utama. |
| `index.html` | Halaman web statis dokumentasi yang dipublikasikan melalui GitHub Pages. |
| `README.md` | Indeks dan penjelasan isi folder dokumentasi. |

## Pemeliharaan

Jika perilaku CLI, katalog, sinkronisasi, atau kebijakan private berubah, dokumen terkait di folder ini perlu diperbarui bersama source agar dokumentasi tidak tertinggal.
